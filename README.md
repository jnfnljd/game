# 프로젝트 소개

- 선수들을 조종해서 축구 경기를 이기는게 목표인 아주 간단한 게임이다. 하지만 경기중에 발로 상대에게 태클을 걸거나 킥을 갈겨도 경고를 받지 않는다.

# 게임 현재 기능

- 선수 wasd 키로 조작과 공 드리블 가능
- 슛 기능 절반정도만 추가됨(좌클릭을 누르거나 홀드해서 슛)
- 조종하고 있지 않은 선수들의 이동 경로나 움직임 일부 구현
- 화면 끝쪽에 있는 벽에서 화면 밖 방향으로 공을 차면 공이 화면 밖으로 나가는 현상 수정
- 가로 방향 말고 세로 방향으로도 슛이 나가는 기능 추가

# 실행 방법

- 시작한 후에 선수를 wasd로 직접 조종한다. r키로 자신이 조종하는 선수를 바꿀 수 있다.(추가 예정) 마우스 우클릭을 0.7~1초정도 누르고 있으면 슛 게이지가 차고 슛게이지가 더 많이 찰수록 강력한 슛이 나가며 슛은 마우스 포인터가 있는 방향으로 나간다. (이것도 추가예정) 등등 있다.
